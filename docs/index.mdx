## Team

The RISC-V team has a dual focus on developing a proof-generating virtual machine (PVM) that executes Linux-compatible RISC-V programs, and an authenticated database solution called _Durable Storage_.

As part of this effort, the team works to integrate these components with the Tezos ecosystem, as well as migrating existing projects to leverage the benefits of the RISC-V PVM and Durable Storage.
